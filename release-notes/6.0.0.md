## 新增

- 新增 AI 楼层总结，可在楼层菜单中总结当前楼层，并结合帖子标题、楼层号和作者信息理解内容。
- 新增用户分析（AI 查成分），基于近期公开主题正文与回复分析兴趣、观点和发言风格；提供「论坛锐评」「详细分析」两种提示词预设，也可自定义提示词。
- 新增 AI 设置，可自备 API Key 接入 OpenAI Chat Completions 兼容服务，支持获取模型列表、手动填写模型和连接测试。
- AI 结果支持流式展示，思考过程默认折叠；支持关闭取消、重试和复制正文。
- 在「实验室」新增「帖子详情兼容模式」，开启后遇到普通方式无法解析的帖子时尝试兼容阅读，支持翻页和本机缓存。
- 帖子楼层作者信息新增 IP 属地，从用户网页资料中获取可用的属地信息。
- 加载界面新增使用提示，介绍页码手势、长按刷新、拖动排序和 AI 功能。

## 删除

- 移除楼层「更多」菜单中的「支持」「反对」「收藏」「查看签名」四项操作。

## 修复

- 修复切页、刷新时不必要的正文重载，以及未变化且仍有效的 IP 属地被反复清空的问题，减少阅读闪烁。
- 修复从「最近被喷」进入回复后点击「显示全部」无法使用「缓存本页」的问题。
- 修复缓存帖子页码排列不一致的问题，页数较少时与在线阅读一样均匀分布。
- 修复部分 AI 服务获取模型列表失败的问题；用户分析会跳过不可用的公开动态，避免混入其他作者的回复，并正确处理正文换行。
