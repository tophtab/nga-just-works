# U2：帖子视频样式与标签支持

状态：2026-09-30 用户已统一确认整体方案，留待新会话实施；批准记录见父任务 approval.md。

## 目标与价值

补齐上游视频尺寸约束和无类型相对附件标签，让视频适应正文宽度并识别已有视频写法。来源 `750871b3`。

## 已确认背景

本 fork 已有 typed video/audio、绝对 Flash 链接、完整页面附件前缀和手动图床；尚缺公共 video CSS 和 `[flash]./…[/flash]` 识别。
普通与兼容来源共用实际正文渲染链，评论/签名也复用公共 decoder。上游新增规则中未转义的点会任意吞字符，不能原样复制。
完整事实、调用点及输入输出见 [研究](research/media-design-evidence.md)。

## 需求与验收

- U2-A1：识别具有明确 `./` 相对路径的无类型 flash 视频，使用完整附件前缀；保留 Unicode、合法 query/fragment 与无扩展名路径。
- U2-A2：原 typed 视频/音频、absolute 链接及其正常输出保持。
- U2-A3/A4/A5：相邻、畸形、未知标记不被新规则吞字或猜地址；特殊字符正确转义，不因单标签失败让整段内容为空。
- U2-A6/A7：页面图床与手动选择保持，普通/兼容显示效果一致；源正文、编辑内容与附件列表链接不被改写。
- U2-A8：大视频不撑出正常正文容器，保留固有比例；小视频不强制拉满，视频独占一行；音频样式和明暗主题保持。
- 通过离线生成/布局检查和项目全模块 Debug 质量门；设备播放与真实服务未测就明确标记未测。

## 范围外

不新增播放器、codec、下载、转码、自动播放或编辑器能力；不改旧 typed/absolute 的所有畸形输入行为，不更换 JSON 库，不改变请求/兼容策略或修复 R7。
不保证相同 URL 的远端内容、未加载媒体的零布局位移或既有祖先容器自身溢出能由本项解决。
