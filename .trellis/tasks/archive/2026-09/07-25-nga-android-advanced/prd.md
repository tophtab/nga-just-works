# NGA Android AI 设置与总结

## Goal

在现有 Android App 中增加一处 AI 设置和两个 AI 总结入口。先完成用户自配 API 的设置能力，再接入楼层总结和用户资料页总结。

当前版本只调用用户配置的第三方 API。App 不提供公共 Key、不承担模型费用，也不接入手机系统模型。

## Confirmed baseline

- 主设置页由 `settings.xml` 和 `SettingsFragment` 承载，可以增加独立的“AI 设置”入口。
- 楼层现有两套三点菜单，点击项已经绑定当前 `ThreadRowInfo`，可以准确取得被点击楼层。
- 用户资料页已有右上角菜单，并在资料加载完成后持有当前页面的 `mProfileData`。
- 本任务启动时工程尚无生成式 AI 产品代码，需要新增独立的 AI 配置、请求和结果展示能力。

## Requirements

### 1. AI 设置（第一步）

1. 在主设置一级页面增加一行“AI 设置”，表现和现有“实验室”入口一致。
2. 点击“AI 设置”后进入独立的二级设置页面；返回时回到主设置页，不新增独立 AI 首页。
3. AI 二级设置页只维护一份当前配置，包含：
   - API 服务地址；
   - API Key；
   - 模型名称。
4. 同一二级页面提供保存、修改、清除配置和简短连接测试。
5. API Key 输入时遮罩显示并加密保存在本机；日志、崩溃信息和普通设置导出中不得出现明文 Key。
6. 当前只支持 OpenAI-compatible Chat Completions 接口。服务地址和模型由用户填写，不内置公共 Key 或共享额度。
7. 二级设置页明确说明：使用总结功能时，相关文本会发送到用户填写的 API 服务。

### 2. 楼层 AI 总结

1. 在两套楼层三点菜单中都增加“AI 总结”。
2. 点击后只总结被点击的当前楼层，输入包含帖子标题、楼层号、作者和该楼层纯文本正文；不读取整帖其他楼层。
3. 未完成 AI 配置时，不发送请求，提示用户先进入 AI 设置。
4. 点击后留在帖子页面并打开共用的可滚动总结弹窗。弹窗显示加载状态、总结结果或可理解的错误，并提供重试和复制；关闭弹窗时取消尚未完成的请求。

### 3. 用户资料页 AI 总结

1. 在用户资料页右上角菜单增加“AI 总结”，仅在当前用户资料加载完成后可用。
2. 总结对象必须是当前资料页中的用户，而不是当前登录账号。
3. 使用该用户近期公开主题和回复生成简要总结。为避免全量抓取，只读取主题第一页和回复第一页，不自动翻页。
4. 未完成 AI 配置时，不发送请求，提示用户先进入 AI 设置。
5. 与楼层总结共用同一个可滚动总结弹窗及其加载、结果、错误、重试和复制能力。

### 4. Shared behavior

1. 两个总结入口共用同一份 AI 配置和同一个 AI 请求实现。
2. AI 请求使用独立的 HTTPS 客户端，不携带 NGA Cookie，也不记录 API Key、请求正文或模型原始响应。
3. 同一时刻只保留当前总结请求；页面退出、对象变化或新请求开始时，旧结果不得显示到其他楼层或用户上。

## Acceptance criteria

真实 API 联调已经执行。配置重载由 JVM 测试覆盖，实际 Keystore/AtomicFile
测试 APK 已编译但未运行。逐项证据与验证边界见 [verification.md](verification.md)。

- [x] 主设置一级页面出现与“实验室”同级的“AI 设置”；点击后进入标题为“AI 设置”的二级页面，返回后回到主设置页。
- [x] AI 二级设置页可以保存 API 服务地址、API Key 和模型名称；重启 App 后配置仍可用。
- [x] API Key 在界面中被遮罩且不会以明文进入日志、备份或普通偏好存储；清除配置后不能继续发起 AI 请求。
- [x] 连接测试能明确显示成功、认证失败、地址错误、网络错误或服务端错误。
- [x] 未配置 AI 时，两个“AI 总结”入口都会引导用户先配置，不产生模型请求。
- [x] 楼层“AI 总结”在两套楼层菜单中均可见，且请求只使用被点击楼层的内容。
- [x] 用户资料页右上角出现“AI 总结”，请求始终绑定当前资料页用户，并且只读取该用户主题第一页和回复第一页。
- [x] 两个入口都在原页面打开同一个可滚动总结弹窗，能够显示加载、结果和错误状态并支持重试、复制；关闭后不会串页显示旧结果。
- [x] 发往 AI 服务的请求不包含 NGA Cookie，API Key、请求正文和原始响应不会写入日志。

## Out of scope

- 手机系统模型、App 内置本地模型或自动选择模型来源。
- 项目提供的免费 API、公共 Key、代理服务器或共享额度。
- 多套 AI 配置、服务商预设、自动拉取模型列表。
- 通用 AI 聊天、多轮追问、流式输出、联网搜索、工具调用和自定义提示词编辑器。
- 整帖总结、用户全部历史抓取或后台自动分析。
- 本任务目录旧版本中混入的其他高级功能；它们不属于本次 AI 工作。
