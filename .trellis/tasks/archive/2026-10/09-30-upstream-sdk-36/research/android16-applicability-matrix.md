# Research: Android 16 complete project applicability matrix

- Query: Map every behavior heading in the current official Android 16 all-app/target-36 pages to concrete current project usage and an implementation decision.
- Scope: mixed; production source/manifests in isolated worktree plus official Android 16 behavior documents, fetched 2026-09-30.
- Date: 2026-09-30
- Baseline: compile35/target35/min29; planned compile36/target36/min29.
- Source-root shorthand: app = nga_phone_base_3.0/src/main; Java paths below app are relative to java unless otherwise specified.

### D. Verification scope and delivery language

Local build preparation and offline checks are specified in platform-toolchain-evidence.md. Plan and final report must distinguish these facts:

1. Source applicability analysis is complete for the current official all-app and target36 lists.
2. Current cached native binaries meet ELF/zip alignment checks; this is baseline static evidence only.
3. SDK36/new AGP/Gradle/Kotlin are absent locally; dependency provisioning is needed after approval before new builds can run offline.
4. No U4 product tests/builds, minified runtime, device install, API36 UI flow, photo picker, navigation animation or 16KB native execution has run in this planning phase.
5. Any unrequested device check is 'not run per project policy'. It neither blocks delivery nor becomes an automatic next task for the user. No ADB probe, device wait, release publication or real NGA request is part of this plan.
