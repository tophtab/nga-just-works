# U1：板块动态图标与刷新

状态：2026-09-30 用户已统一确认整体方案，留待新会话实施；批准记录见父任务 approval.md。

## 目标与价值

让普通板块和合集的远程图标跟随分类接口提供的有效前缀变化，减少固定图标域名变化造成的失效。“动态”指地址动态获取，不是动画。

## 已确认背景

- 上游 `6a785430` 提供 `forum_icon_pre → iconUrl` 链；`750871b3` 修改一次性刷新 key。
- 本 fork `1a8413d9` 仍用可用的固定 HTTPS 默认地址，内置 drawable 优先，实际远程 UI 使用 Coil。
- 当前刷新仅在新增板块非空时合并；已有原始分类缓存可用于读取旧版本没有消费的前缀。
- 收藏树和普通树可能包含同一板块的不同对象，map 不能代表所有显示节点。收藏、主页自定义顺序与根树持久化是本 fork 必须保留的行为。
- 依据：[父调研索引](../09-30-upstream-adoption/research/source-index.md)、[当前源码复核](research/upstream-refresh-and-url.md)、[状态复核](research/state-persistence-ui.md)。

## 需求

| ID | 要求 | 对应验收 |
| --- | --- | --- |
| U1-R1 | 普通/合集图标采用有效服务端前缀，保留负 fid、合集优先与当前可用默认；内置图标的显示优先级保持 | A1、A2、A10 |
| U1-R2 | 没有新增板块而只有前缀变化时，已有普通树、收藏和重复显示节点均能更新；新增节点也立即获得正确图标并可见 | A3、A4、A5 |
| U1-R3 | 缺失/非法元数据、请求失败或缓存损坏不清除有效图标、不使本地列表不可用；不为此增加自动重试 | A2、A6、A9 |
| U1-R4 | 收藏成员、稳定键、账号无关性、拖动/回滚、首页顺序、板块根层级和点击行为保持 | A7、A8、A10 |
| U1-R5 | 保持原每日请求节流；升级复用有效缓存，不能为图标迁移删除板块/收藏数据或重置排序 | A6、A8、A9 |

## 验收标准

- U1-A1/A2：有效前缀生成正确的普通/合集 URL；无效输入保留上次有效值或默认。未知路径布局不猜测合集规则，具体可接受输入见设计契约。
- U1-A3/A4：只有前缀变化时，所有相关实际实体的图标及可观察状态更新，无须等新增板块或重启。
- U1-A5：新节点出现在原所属分类，有正确图标，旧节点顺序保持。
- U1-A6：旧 JSON、原始分类缓存和重启路径兼容，坏图标元数据不会破坏本地数据。
- U1-A7/A8：刷新前后收藏/主页顺序与根树一致；拖动期间刷新与后续取消/写入失败不回退新状态；只改图标不会重写列表文件。
- U1-A9：升级无缓存时使用默认图标，到下次正常到期请求后更新；正常时钟下等待不超过剩余一天间隔。重复触发仅保留一次在途请求，取消/失败不形成快速重试。
- U1-A10：内置图标、错误占位、尺寸、当前页/滚动、点击、拖动和无障碍排序保持。
- 离线行为测试及项目规定的 Debug 构建、全模块单测/lint 通过；未做设备/真实服务验证时不声称已通过。

## 范围外

不更换图标设计、不加用户开关、不调整正文图床；不清全局图片缓存、不保证相同 URL 的 CDN 内容强制更新；不扩展无来源依据的未知图标目录协议。
U2 视频、U3 JSON/模型迁移、U4 SDK、其他会话 R1–R6 工作与 R7 产品修复均不在 U1 实施范围。不发布、不做设备操作或真实 NGA 请求。
