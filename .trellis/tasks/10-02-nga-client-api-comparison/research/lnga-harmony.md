### Files found and architecture

All paths beginning `service/`, `parser/`, `store/`, `pages/`, or `common/` below are relative to `entry/src/main/ets/`.

- `service/NgaClient.ets`: HarmonyOS HTTP primitive, signed forms, login/logout and decoding.
- `service/api/*.ets`: operation-specific request construction and result projection.
- `common/security/NgaSigner.ets`: app signature/client checksum construction; referenced by the actual transport.
- `common/utils/SubjectListQuery.ets`: pure request and signature rules for forum lists/search/hot/topped/subscription.

- `entry/src/test/`: Hypium parser/query/policy tests; `tools/bbcode-ts/tests/`: additional HTML/BBCode tests.

### Shared wire contract and important transport limitations

Signed operations below use POST to **https://ngabbs.com**, regardless of the selected general domain. `__lib` and `__act` are URL query fields; business fields and `__output`, `__inchst`, `app_id`, `access_uid`, `access_token`, `t`, `sign` are URL-encoded body fields. Cookie carries the same uid/cid. `signParams` is an operation-specific concatenated string; the shared signer consumes app ID, uid, token, that string, timestamp and built-in secret. This report deliberately does not reproduce secret values. Checksum is optional per operation. See [service/NgaClient.ets:261](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L261), [service/NgaClient.ets:295](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L295), [service/NgaClient.ets:326](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L326), [service/NgaClient.ets:365](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L365).

Headers imitate Android NGA 7.17.17: browser UA, X-Requested-With, official channel/version name/code, X-USER-AGENT and ngabbs Referer. A lower-level `X-User-Agent: Nga_Official` is also inserted before extra headers; differing-case header keys merit normalization when porting ([service/NgaClient.ets:176](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L176)).

UTF-8 percent-encoded forms are built by [common/utils/CodecUtils.ets:400](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/common/utils/CodecUtils.ets#L400). Signed responses default UTF-8; `read.php __output=8` tracking explicitly selects GB18030 ([service/NgaClient.ets:418](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L418)). Login response is GB18030; binary captcha is returned as a PNG data URL. These are operation-specific encoding facts, not a universal “NGA uses GBK” rule.

HTTP uses NetworkKit ARRAY_BUFFER, connect timeout 15 seconds/read timeout 30 seconds and destroys each handle in its callback ([service/NgaClient.ets:91](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L91)). The shared executor catches **transport errors only**, retries up to two further attempts because the domain array has three entries, and does this for POST as well as GET. For signed calls the fixed base URL means all three attempts hit **the same ngabbs.com host**; the domain selector does not change them. Login similarly pins bbs.nga.cn; logout can rotate domains. No operation/idempotency distinction, unknown mutation outcome, retry-after handling, HTTP status rejection, response-size bound, redirect policy override, or caller cancellation handle is evident in this HTTP primitive ([service/NgaClient.ets:162](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L162), [service/NgaClient.ets:438](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L438)). HTTP failures with a body are parsed, not automatically retried by status. This is materially weaker than the current project's access rules.

`ngaThrottler` provides six concurrent requests per host and a minimum **150 ms dispatch-to-dispatch** gap, not a terminal gap ([common/concurrency/Throttler.ets:26](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/common/concurrency/Throttler.ets#L26), [common/concurrency/Throttler.ets:94](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/common/concurrency/Throttler.ets#L94)). Binary captcha and uploads bypass that executor/throttler. App-scope guards elsewhere can discard stale results but do not add physical cancellation to this primitive.

Verbose logging masks only urlencoded `access_token/access_uid/sign/password` values; it still logs decoded response bodies and URL/body content ([service/NgaClient.ets:63](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L63), [service/NgaClient.ets:452](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L452)). Private-message content, profile data, upload tokens, and multipart login fields are not comprehensively scrubbed. Do not port these diagnostics.

NgaJsonSanitizer removes the script assignment and specific NGA comment tokens, quotes certain plus-prefixed / leading-zero numeric text fields, and escapes control characters while tracking JSON strings ([parser/NgaJsonSanitizer.ets:28](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/parser/NgaJsonSanitizer.ets#L28), [parser/NgaJsonSanitizer.ets:37](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/parser/NgaJsonSanitizer.ets#L37)). Shared handling returns either parsed object, HTML-derived `error/error_code`, or `__parseError` object ([service/NgaClient.ets:455](https://github.com/apap6628114/lnga_harmony/blob/df6cfcc2e4cfc2efa95269aac398707e9d4d3e81/entry/src/main/ets/service/NgaClient.ets#L455)). ### Concrete adoption assessment for nga-just-works

1. **High-value API references:** signed subject list/search/hot/topped and subforum subscription rules; fuller favorite-folder CRUD; follow/follower/feed; app private messages/notifications; post/check and quote/edit attachment preservation. These fill specific operation-contract gaps compared with the existing Justwen legacy nuke/post.php registry.
2. **Useful read alternative, distinct migration:** read.php O17 HTML offers native reconstruction and explicit error-template handling, whereas this project currently uses ordinary O8 plus app_api post/list compatibility. Porting requires its own raw/source/query identity and fixtures; it is not an in-place endpoint substitution.
3. **Useful encoding evidence:** preserve per-operation O17 UTF-8 versus O8 GB18030, blank output/inchst for post content, exact signParams ordering and subject UTF-8 byte bounds. Treat upstream service claims as candidate contracts pending offline fixtures and authorized validation.
4. **Reject transport behavior as-is:** replace automatic mutation retry, body logging, permissive status/success projection and unchecked server upload URL with current project's mandatory session/origin/redirect/unknown-outcome boundaries. Six-per-host throttling is not equivalent to current bounded terminal-gap queues.
5. **Keep scope explicit:** no implemented NGA report endpoint, remote keyword/blacklist write, signature/avatar change, private-message delete, or wager settlement was found in the API layer. Local filter/storage features do not establish those remote capabilities. Login UI/QR/Web support requires separate UI-specific analysis if selected for migration.
