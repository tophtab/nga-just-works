Every table row is a **POST** to `https://ngabbs.com/<path>?__lib=<lib>&__act=<act>`. Rows give path/lib/act separately to reduce repetition. For form endpoints Retrofit @Field values are decoded strings, then the signing interceptor rebuilds an OkHttp FormBody (UTF-8 default); there is no GBK transform in this path.

Common signed fields: `access_uid`, `access_token`, `app_id=1010`, `t` (epoch seconds), `sign`, `__output=14`. Body-less @POST declarations receive Retrofit's POST body and thus also pass through the interceptor's non-null-body branch; the source does not omit signing for login/category/followed-board reads. Signature input uses operation-specific tuples; reply/quote uses tid/content, new-post branch uses fid/subject/content, general branch uses fid/tid/pid/uid-or-id/key/value. PID is excluded from the general signature when tid is empty/zero, although it remains in the request body. `__ngaClientChecksum` is added for post/new, reply and quote ([utils/interceptor/SignInterceptor.kt:106](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/utils/interceptor/SignInterceptor.kt#L106)). No secret values are reproduced here.

Headers are fixed browser `User-Agent` plus `X-USER-AGENT: Nga_Official/90941(Xiaomi;Android 14)`. API auth is app token + uid in the form, **not** ngaPassportUid/ngaPassportCid Cookies. Credentials come from mutable global StorageUtils at interception time. All methods attempt dispatch even with empty token/uid=0; login is naturally bootstrapped that way. Private reads and writes semantically need a session, but anonymous eligibility for each read cannot be proven from declarations. PostScreen gates comment submission on isLoggedIn; vote submission requires positive uid. There is no centralized per-operation session preflight.

### Parsing, state effects, and transport limits

- Common envelope: Gson converter parses body via standard response charset handling (Content-Type/BOM/default UTF-8), not a custom always-GBK converter. `BaseResponse` starts with CODE_ERROR; only `code == 0` yields LoadingState.Success. Unknown codes collapse to CODE_ERROR. No JS-wrapper stripping, NGA HTML challenge parser, byte-size cap, or malformed-numeric repair exists here. Useful modern envelope, but not evidence that web-format parsing is unnecessary elsewhere.
- AuthInterceptor independently peeks the **entire** response using `peekBody(Long.MAX_VALUE)`, parses JSONObject, and codes 46/2048 clear global uid/token and navigate to login. This reads/parses the body twice and lacks an operation/account snapshot. A stale request can log out a newer session. Parse exceptions print stack traces. [utils/interceptor/AuthInterceptor.kt:15](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/utils/interceptor/AuthInterceptor.kt#L15).
- NetworkRepo resumes with HTTP body, otherwise turns non-2xx into RuntimeException with up to 200 response characters, or reports null body. Exceptions are logged with message/stack and returned as display strings; therefore bounded raw error-body snippets may reach logs. No typed auth/challenge/rate-limit/UnknownOutcome taxonomy. [logic/repository/NetworkRepo.kt:225](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/logic/repository/NetworkRepo.kt#L225).
- `suspendCoroutine` wraps enqueue without cancellation propagation to Call.cancel. Flow catches Exception; it does not preserve a dedicated cancellation path. OkHttp builder overrides neither retryOnConnectionFailure nor redirects/timeouts; defaults apply, so “no application retry loop” does **not** establish no transport retry for writes. No explicit backoff, rate limiter, immutable auth snapshot, host allowlist on redirects, or idempotency token.
- Credentials are persisted through plain app-private SharedPreferences, not a protected credential store: [utils/StorageUtils.kt:9](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/utils/StorageUtils.kt#L9).
- Reply/quote: local in-flight guard; validate thread/forum/target pid/floor; only success clears composer; defer refresh until current page load finishes. [post/PostViewModel:194](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/ui/post/PostViewModel.kt#L194) and [post/PostScreen:281](https://github.com/Night-stars-1/compose-nga/blob/8ac09f45fdaab5032d09cf5aa2b2aad5b7e8e595/app/src/main/java/com/srap/nga/ui/post/PostScreen.kt#L281). Generic code-0 response suffices even when result is absent/non-string; timeout ambiguity remains.
- Vote: result accepts an object or array of objects, selects the first valid last_state in [-1,0,1], otherwise null. ViewModel refuses local success mutation if null and asks user to refresh. ## Caveats / Not Found

- Static source proves implementation intent and reachable code, never present-day server acceptance, permissions or endpoint longevity.
- No live login, requests, uploads, mutations or media fetches were made.
- No new-topic API despite sign helper support; no poll voting despite poll rendering.
- No assurance of safe automatic write retries: transport defaults are not explicitly disabled.
- No universal normalization advantage: app JSON still contains mixed arrays and permissive/null adapters.
- No evidence that app_token and passport cid are interchangeable.
- Current-project source comparisons are local observations; the coordinator's four-way comparison pins the current revision. Recommendations above intentionally avoid claiming source compatibility or measured performance improvement.
